ReproImage

Integrity, provenance and reproducibility checks for scientific images. Point it at a folder of figures and it lists identical files, identical pixels saved in another format, and visually similar images, including rotated, flipped and re-contrasted copies.

Example report Source Algorithms
Results need expert review. ReproImage reports visual relations between images, never misconduct. A similar pair may be a legitimate reuse, a control shown twice, or an honest error.

Python

pip install git+https://github.com/pablosancheznunez/reproimage
reproimage analyze figures/ --out report/

The output folder holds report.html (self-contained, side-by-side comparisons), result.json, pairs.csv and ro-crate-metadata.json, a provenance record compatible with W3C PROV that lists every input with its checksum, the tool version and the parameters.

R

remotes::install_github("pablosancheznunez/reproimage", subdir = "r")
library(reproimage)
res <- ri_analyze("figures/")
ri_pairs(res)
ri_write(res, "report/")

The R package implements the same written specification and is tested against the same reference images: both give identical results.

What it detects

CategoryHow
Identical filesSame SHA-256 of the file bytes
Identical pixelsSame SHA-256 of the decoded pixels, for example the same image saved as PNG and TIFF
Visually similarDifference and perceptual hashes within a distance threshold, checked in eight orientations (rotations and flips)

Known limits

  • Hashes describe the whole image. A duplicated region inside an otherwise different image (for example one spliced gel lane) is not detected yet.
  • Strong crops or resizing beyond a few percent can push similar images past the threshold.
  • 16-bit colour images are reduced differently by different decoders; they are analysed but not part of the conformance tests.

Reference dataset

Twelve synthetic gel and fluorescence images with known relations (copies, format changes, rotations, flips, contrast changes, a splice and unrelated negatives), generated by a deterministic script and stored with the expected results. Both implementations must reproduce them exactly.
